Ferrite DB Explorer

In-browser vector search powered by ferrite-wasm running in a Web Worker.

1 · Dataset

Metadata Schema

Columns must have a non-empty name (no NUL bytes), unique names, and a type of bool, i64, f64, or string. Leave empty for vector-only tables.

Source

Vectors are drawn around clusters random centroids using a seeded PRNG. A cluster (i64) metadata column is auto-added when the schema has an i64 column named cluster.

JSON: an array of {"id?":n,"vector":[..],"metadata"?":{col:val}}. CSV: header id?,dim0,...,col1,....
